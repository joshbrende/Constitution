# Executive summary — ZANU PF Constitution & Academy Platform

## Recommendation

**Approve a two-province pilot**, then **national rollout** after a 90-day review of enrolments, certificate workflow, and security audit results.

## What this platform delivers

A single digital environment for:

1. **Constitutional literacy** — ZANU PF party constitution, national constitution, and amendments (web + mobile, offline on mobile).
2. **ZANU PF Academy** — structured courses, assessments, and membership certification aligned to **offline payment** and **Presidium approval**.
3. **Member services** — profile, provincial affiliation, dialogue, library, and party information.
4. **Administration** — national and **provincial** back-office with audit trails and role-based access.

## Why it fits the party

| Party need | Platform response |
|------------|-------------------|
| Mass education on constitution | Mobile offline reader + optional guest browse |
| Controlled membership certification | Multi-step certificate workflow, not instant download |
| Provincial autonomy with national oversight | Provincial admin scope; Presidium approval gate |
| Accountability | Append-only audit logs with integrity verification |
| ICT sovereignty | Deployable on party/government infrastructure (Docker or WAMP) |

## Readiness status (post-hardening)

| Area | Status |
|------|--------|
| Core features | **Ready** for pilot |
| Security baseline | **Ready** with documented residual risks |
| National ID live verification | **Pending** government ICT integration (collection only today) |
| App Store / Play Store | **Ready** to submit after EAS credentials configured |
| Penetration test | **Scheduled** — required before national scale |

## Decision requested

1. **Endorse** provincial pilot provinces (recommended: two with strong ICT liaison).
2. **Mandate** Presidium workflow owners for certificate approval SLAs.
3. **Authorize** ICT to complete National ID portal integration when Gov ICT MOU is signed.
4. **Approve** public communication plan (member registration, academy, certificate collection).

## Risks if we delay

- Continued reliance on informal training records without verifiable certificates.
- Uneven constitutional awareness across provinces.
- Manual provincial reporting without central analytics.

## Risks if we rush nationally

- Unverified National ID claims if marketed as “government verified” before integration.
- Provincial admins under-trained on certificate payment confirmation.

**Bottom line:** The platform is **fit for phased political adoption**. National scale should follow pilot metrics and external security sign-off.
